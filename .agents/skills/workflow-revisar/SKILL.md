# Contexto compartido

Lee ../../../docs/METODOLOGIA.md y ../../../docs/CONTRATO.md desde el directorio físico
.agents/skills/workflow-<operacion>/. Trabaja sobre el proyecto destino y sus AGENTS/estado/progreso.
Conserva evidencia, decisiones y límites. No inventes aprobación, asignación de roles ni integración.

Determina autor y base real. Si escribiste el cambio, prepara pedido al otro rol/modelo y deja revisor vacío. En revisión independiente lee diff y criterios, ejecuta comprobaciones y busca fallos con escenario. Usa el formato de sección 5, publica solo con autorización o guarda local. No marques hecha hasta integración confirmada.
