# Instrucciones del proyecto

Lee docs/METODOLOGIA.md y docs/CONTRATO.md, workflow/features.json y últimas entradas de PROGRESO.
Ejecuta node workflow/workflow.mjs estado al iniciar y metodologia al cerrar.
Roles genéricos: human, agent-a, agent-b. Confirma la asignación real; nadie revisa su propia entrega.
No incorporar datos personales, marcas privadas, secretos o información de otros proyectos.
Para trabajo nuevo usa rama por función y base development, salvo indicación expresa distinta.
Tests: node --test test/*.test.mjs. No debilitar controles para pasar. No hacer merge ni desplegar
sin autorización. Documenta qué se probó y qué no; revisor vacío hasta revisión efectivamente emitida.
